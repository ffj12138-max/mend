mend is one patch tool for every AI edit format: it applies unified diffs (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and JSON text-editor tool calls to a tree of text files, matching lines at three tiers (exact, trailing-whitespace-insensitive, and indentation-insensitive with re-indentation), and changes every file or nothing. See `SPEC.md` for the full specification it implements.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
